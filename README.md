## Objetivo
El proyecto presenta un prototipo funcional multiplataforma — móvil y escritorio — que aborda las principales fricciones del Aula Virtual actual: 
- Falta de adaptación a dispositivos móviles
- Ausencia de seguimiento visual del progreso académico
- Desconexión entre el estudiante y su entorno digital universitario
